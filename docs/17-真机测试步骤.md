# 真机测试步骤

> 目标：在 iPhone / iPad 上验证 ONScripter 与 KiriKiri 两个引擎能装载游戏、出画面、响应触控。

## 1 拿到 ipa

CI 每次 `ios` 工作流成功后都会产出未签名的 ipa：

- GitHub Actions → `ios` → 最新一次成功运行 → Artifacts → `Aurora-unsigned-ipa`
- 解压得到 `Aurora-unsigned.ipa`

ipa 里已经包含：两个引擎的可执行代码、`ModuleManifests/` 清单、`TestGames/minimal-ons` 和
`TestGames/minimal-krkr` 两个冒烟素材。

## 2 安装（自签）

需要一台 Windows 或 Mac、一根数据线、一个 Apple ID（免费账号即可）。

1. 装 [Sideloadly](https://sideloadly.io/)；
2. 手机连电脑，Sideloadly 选中 `Aurora-unsigned.ipa`，填 Apple ID；
3. 开始后手机会要求"信任开发者"，到 设置 → 通用 → VPN与设备管理 里信任；
4. 首次启动若提示"不受信任的开发者"，重复第 3 步。

免费账号签的应用 **7 天后失效**，过期需重签。Bundle ID 是 `com.aurora.app`，
如果提示冲突，在 Sideloadly 里改一个后缀。

## 3 放游戏

两种方式：

**Files 应用**：把游戏文件夹（或整个 `data.xp3` 所在目录）拷进
`文件 → 我的 iPhone/iPad → Aurora`，然后回 App 点 `Rescan`。

**App 内导入**：右上角 `Import` 选目录。

识别规则来自各模块的清单：

| 引擎 | 识别到的文件 |
|---|---|
| ONScripter | `0.txt` / `00.txt` / `nscript.dat` / `0.utf` |
| KiriKiri | `data.xp3` / `startup.tjs` / `*.xp3` / `*.ks` |

## 4 验收清单

按顺序做，每步记下结果：

1. **库列表**：两个内置素材 `minimal-ons`、`minimal-krkr` 都在，模块列显示 READY。
2. **ONScripter 出画面**：点 `minimal-ons` 的 Run，`Runtime output` 面板出现 640×480 的画面，
   能看到冒烟脚本里的文字。面板下方 `frames presented` 在增长。
3. **KiriKiri 出画面**：点 `minimal-krkr` 的 Run，面板变成 1280×720，`frames presented` 增长。
4. **触控**：在 ONScripter 画面上点一下（推进对话），KiriKiri 画面上点一下。
   两个引擎都不应崩溃，日志里出现对应的 pointer / mouse 事件。
5. **真实游戏**：放一个自己的 `.xp3` 游戏进去，Run，观察是否出现标题画面。
6. **退出**：点 Stop，模块回到 READY，App 不崩。

## 5 已知限制

- **画面呈现**：宿主把帧画在 `Runtime output` 面板里，不是全屏游戏视图；触摸坐标目前按面板尺寸换算。
- **音频**：两个引擎走自己的 SDL 音频通道，App 侧不参与混音；静音开关会影响输出。
- **存档**：KiriKiri 的存档写在游戏目录下的 `savedata/`；ONScripter 写到 App 的 Saves 目录。
- **真机签名**：免费账号 7 天；企业证书另说。

## 6 出问题时抓什么

真机上没有 CI 的日志通道，按下面顺序取：

1. App 内 `Log` 区块（诊断信息，含模块状态与最近错误）；
2. Xcode → Window → Devices and Simulators → 选中设备 → Open Console，过滤进程 `Aurora`；
3. 崩溃的话，设置 → 隐私与安全性 → 分析与改进 → 分析数据，找 `Aurora-*.ips`。

把这三样里的任意一样贴回来就能定位。
