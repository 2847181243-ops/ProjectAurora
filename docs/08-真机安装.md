# 08 装到真机

这份文档描述当前这台 Windows 机器上把未签名 ipa 装进 iPhone/iPad 的实际步骤。
不是通用教程，是这台机器上已经验证过的路径。

## 1. 前置

- iPhone 或 iPad，系统 ≥ 16.0（App 的 MinimumOSVersion 是 16.0）
- 一个 Apple ID（免费账号即可，签名 7 天有效）
- Windows 侧需要：Apple 的 USB 驱动（随 iTunes 安装）+ Sideloadly

## 2. 装工具

1. 安装 iTunes（提供 Apple Mobile Device Support 与 USB 驱动）
2. 安装 Sideloadly
3. 手机插上电脑，手机上点"信任此电脑"

注意：Windows 上桌面版 QQ 与 NapCat 不能同时在线，与这里无关，但插设备前先确认没有别的
程序占用 USB 调试通道。

## 3. 签名安装

1. 打开 Sideloadly，把你的 Apple ID 填进 Apple account 一栏
2. IPA 选 `out/Aurora-unsigned-ipa/Aurora-unsigned.ipa`
3. 点 Start，输入 Apple ID 密码（首次会要求专用密码或二次验证）
4. 完成后手机会出现 Aurora 图标

## 4. 首次启动前

iOS 16 之后侧载的 App 需要在设置里信任：

设置 → 通用 → VPN 与设备管理 → 开发者 App → 选择你的 Apple ID → 信任

iOS 16+ 可能还需要开启"开发者模式"：
设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启

## 5. 打开后应该看到什么

- 顶部一列模块，右侧是状态徽章：READY / DISCOVERED / FAILED
- `com.aurora.runtime.ppsspp` 应该显示 DISCOVERED，原因"not compiled into this build"
- `com.aurora.runtime.simulated` 是 READY，点 Run 之后下面出现一条渐变加移动色带的画面
- frames presented 的数字随帧上涨

如果 simulated 显示 FAILED 或画面区一直是 "Waiting for the first frame"，就是有问题，
把屏幕截图发我。

## 6. 过期与重签

免费 Apple ID 签的 ipa 7 天后失效，App 打不开。重新用 Sideloadly 走一遍第 3 步即可，
数据不会丢（存档在 App 的 Application Support 里，重签同 bundle id 覆盖安装）。
