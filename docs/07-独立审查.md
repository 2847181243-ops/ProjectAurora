## 2. 发现与处理

## 3. 审查方确认没问题的部分

- vtable 主版本、module_id、必需指针对检查
- 构建表 id 与二进制自报 id 不一致会被拒
- Manifest 写 status=ready 无法得到 READY（有真实测试覆盖）
- 状态迁移只走状态机边表，派生状态走最短路径而不是直接赋值
- 存储层拒绝 `..`、反斜杠、盘符、绝对路径
- 生成的构建表与 `generate_builtin_table.py` 输出一致
- 全仓库没有 dlopen/dlsym
- Host 服务是每模块一份绑定，不是全局
